# PFAS_DT_Investigator
This repository contains all the Python codes for the software PFAS DT Investigator.vo. But for modifying this software you have to put the revised code into the Beeware framework. Please check the demonstration by Beeware for detail guilidine for the code integration.

The csv file, 'Pre_Trans_Lib.csv', is the constructed precursor teansformation library that is organized as the format ready for the software 'PFAS_DT_Investigator.v.0' to read. The user can add new transformation pathways into this csv file and should replace the old version of libray at "***\pfas_dt_investigator\src" with the updated library.
